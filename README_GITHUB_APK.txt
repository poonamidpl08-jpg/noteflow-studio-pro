NoteFlow Studio Pro - GitHub Actions Cloud APK Build (No Android Studio Needed)
================================================================================

Steps to generate your installable Android APK for free in ~2 minutes:

1. Extract this ZIP file on your computer.
2. Go to https://github.com and sign in (or create a free account).
3. Click '+' (top right) -> 'New repository', give it a name like 'noteflow-studio-pro',
   keep it Public or Private, and click 'Create repository'.
4. Click 'uploading an existing file'.
5. Open the extracted folder, select ALL files and folders inside it
   (including '.github', 'app', 'build.gradle', 'gradle.properties', 'settings.gradle'),
   drag and drop them onto GitHub, and click 'Commit changes'.
   (Note: Make sure the '.github' folder is included. In Windows File Explorer,
    enable View -> Show -> Hidden items if you don't see '.github'.)
6. Click the 'Actions' tab at the top of your GitHub repository.
7. You will see 'Build NoteFlow Studio Pro APK' running automatically
   (or click it -> 'Run workflow').
8. Once the green checkmark appears (~2 minutes), click the completed run,
   scroll to the 'Artifacts' section at the bottom, and click
   'NoteFlow-Studio-Pro-APK' to download your ZIP containing 'app-debug.apk'.
9. Extract 'app-debug.apk', transfer it to your 75-inch Android 16 IFP, and install!
